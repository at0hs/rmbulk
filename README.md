# rmbulk

CSV / Excel に書いたチケットを、確認画面を経て Redmine に一括登録する CLI です。

- Windows、PowerShell 5.1 / 7
- Excel ファイルを読むには Excel がインストールされている必要があります（CSV だけなら不要）

## 使い方

```bat
rmbulk.cmd setup                   :: 最初に1回。URL と API キーを入力し、接続を確認して保存する
rmbulk.cmd template [<出力先>]     :: 列名だけが入ったひな形 CSV を出力する（既定: rmbulk_template.csv）
rmbulk.cmd import <ファイル>       :: CSV / Excel を読み込み、一覧を確認して y で登録する
rmbulk.cmd refresh                 :: プロジェクト一覧などを取り直す（普段は不要）
```

API キーは Redmine の「個人設定」画面の右側にある「API アクセスキー」で確認できます。

`import` の流れ:

1. ファイルを読み込み、内容をチェックして一覧を表示します。エラーがあれば一覧の下に表示して終了します（登録はしません）。
2. `登録しますか？(y/n)` で `y` を入力すると登録します。
3. 最後に `成功 ○件 / エラー ○件 / スキップ ○件` と、ログファイルの場所を表示します。

## 入力ファイル

1行目が列名、2行目以降が1行1チケットです。列の順番は自由です。Excel は先頭のシートだけを読みます。

| 列名 | 必須 | 内容 |
|---|---|---|
| 仮番号 | | ファイル内で親を指定するための番号（正の整数、重複不可） |
| プロジェクト | ○ | プロジェクト名、または識別子 |
| トラッカー | ○ | tracker 名（例: タスク） |
| 題名 | ○ | |
| 説明 | | |
| 開始日 | ○ | `2026-11-04` または `2026/11/04` |
| 期日 | ○ | 開始日と同じ形式。開始日以降 |
| 対象バージョン | ○ | バージョン名 |
| 親チケット | | 既存チケットの番号（例: `123`）、またはファイル内の仮番号（例: `#1`） |

例:

```csv
仮番号,プロジェクト,トラッカー,題名,説明,開始日,期日,対象バージョン,親チケット
1,WBS,タスク,設計,,2026-11-04,2026-11-10,v1.0,
2,WBS,タスク,画面設計,,2026-11-04,2026-11-06,v1.0,#1
3,WBS,タスク,DB設計,,2026-11-07,2026-11-10,v1.0,#1
```

CSV の文字コードは UTF-8（BOM あり・なし）と Shift-JIS に対応しています。

## 一部の登録に失敗したとき

ログ（`logs/rmbulk_日時.log`）に、行ごとの結果（成功したチケット番号、エラーの内容、スキップした理由）が残ります。
失敗した行とスキップした行だけを残したファイルを作って再実行してください。
成功した親を `#n` で参照している行は、ログにあるチケット番号に書き換えてください。

## 保存されるファイル

ツールのフォルダに次のファイルを作ります。フォルダごと削除すれば何も残りません。

| ファイル | 内容 |
|---|---|
| `config.json` | Redmine の URL |
| `apikey.dat` | API キー（Windows の DPAPI で暗号化。保存した本人がそのPCでしか復号できない） |
| `metadata.json` | プロジェクト・tracker・バージョンの一覧 |
| `logs/` | 実行ログ |

他の人にツールを渡すときは、フォルダごとコピーしてもらい、各自で `setup` を実行してもらってください。

## 開発

テスト（Pester 5 以降）は PowerShell 7 と 5.1 の両方で実行します。

```powershell
pwsh -NoProfile -File tests/Run-Tests.ps1                         # 単体テスト
pwsh -NoProfile -File tests/Run-Tests.ps1 -Path tests/integration # 結合テスト（Docker が必要）
```

結合テストは `redmine:6` イメージを `http://127.0.0.1:3030` で起動し、テスト用のプロジェクトとバージョンを作ってから実行します（初回はイメージの取得とデータベースの初期化に数分かかります）。`localhost` は IPv6 で接続しようとして応答しないことがあるため、`127.0.0.1` を使っています。
Excel を使うテストは、Excel がインストールされていない PC では自動でスキップされます。

結合テストの後片付け:

```powershell
docker compose -f tests/integration/docker-compose.yml down -v
```

`.ps1` ファイルは UTF-8 BOM 付きで保存してください（BOM がないと PowerShell 5.1 が日本語を読めません。テストで検査しています）。
